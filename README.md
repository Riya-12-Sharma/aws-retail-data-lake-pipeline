# AWS Retail Data Lake — Sales Dashboard A data engineering project that cleans retail order data and presents sales insights in Power BI. The project includes Python/Pandas ETL code and supporting AWS Glue and Amazon Athena files. ## Project Overview The pipeline processes retail order data, separates valid and rejected records, creates a data quality report, and uses the curated data for sales analysis. ## Tech Stack - Python and Pandas - SQL - Amazon S3 - AWS Glue and PySpark - Amazon Athena - Power BI - Git and GitHub ## Project Flow ```text Raw Orders CSV → ETL and Data Cleaning → Curated and Rejected CSVs → Data Quality Report Curated Orders CSV → Power BI Sales Dashboard AWS components included in the project: Amazon S3, AWS Glue ETL script, and Athena SQL queries. ``` ## Key Features - Clean and validate retail order data - Identify invalid records - Produce curated and rejected datasets - Generate a data quality report - Analyze sales by category, region, and order status - Include AWS Glue ETL code and Athena SQL queries ## Power BI Dashboard - **Total Sales:** 9.28K - **Total Orders:** 180 - **Total Quantity Sold:** 433 - Sales by Category - Sales by Region - Orders by Status These values are based on the current sample dataset. ## Screenshots ### 1.
